# Жанақала Такси Бот

Telegram такси боты (жолаушы + жүргізуші) + веб-негізді әкімші панелі.

## Құрамы
- `bot.py` — Telegram бот логикасы (клиент/жүргізуші) — **өз алдына жеке процесс/сервис ретінде іске қосылады**
- `admin_app.py` — Flask веб-әкімші панелі логикасы — **сол сияқты өз алдына жеке процесс/сервис**
- `database.py` — дерек қорының қабаты. `DATABASE_URL` орнатылса — PostgreSQL-ге қосылады (бот пен панель екі бөлек серверде/сервисте жүрсе де бір базаны көреді). Орнатылмаса — жергілікті `taxi.db` (SQLite) файлын қолданады, тек локал тестілеуге ыңғайлы.
- `app.py` — **ескі, қосымша нұсқа**: бот пен панельді бір процесте қосады. SQLite-пен локал тестілеу/демо үшін пайдалы, бірақ енді хостингте қолданудың қажеті жоқ (төмендегі PostgreSQL нұсқасы дұрысы).
- `templates/` — админ панельдің HTML беттері (жаңа заманауи sidebar дизайн)
- `Procfile` — Railway-ге бот пен панельді **екі бөлек процесс** ретінде деплой ету үшін

## 🗄 Архитектура: бот пен панель бөлек, база біреу

Бұрын бот пен панельді екі бөлек сервиске шығарғанда, әрқайсысының **өз дискісі** болғандықтан, екеуі шын мәнінде екі бөлек `taxi.db` файлымен жұмыс істеп жатты. Енді бұл `database.py`-ды **PostgreSQL** қолдайтындай етіп өзгерту арқылы шешілді: PostgreSQL — желі арқылы қосылатын бөлек сервер, сондықтан `bot.py` мен `admin_app.py` екі мүлдем бөлек процесс/сервис ретінде жұмыс істеп, бәрібір **бір базаға** қосыла алады. Бот пен панельдің ішкі логикасы (барлық SQL сұраулары) бір ғана жерде — `database.py`-да — болғандықтан, бұл ауысу екеуінің де негізгі кодын өзгертпей-ақ жасалды.

### Railway-ге деплой (ұсынылатын нұсқа)

1. **PostgreSQL қос:** Railway жобаңда "New" → "Database" → "Add PostgreSQL". Railway автоматты `DATABASE_URL` айнымалысын жасайды.
2. **Бот сервисі:** сол репозиторийден "New" → "GitHub Repo" → осы `taxi-bot` папкасын таңда. Settings → Start Command = `python3 bot.py` (немесе Procfile-дегі `bot` процесін таңда). Variables: `BOT_TOKEN`, `ADMIN_CHAT_ID`, және PostgreSQL сервисінен `DATABASE_URL`-ды сілтеп қос (Railway "Variable Reference" арқылы басқа сервистің айнымалысын тартып алуға болады).
3. **Панель сервисі:** сол репозиторийден тағы бір сервис жаса. Start Command = `python3 admin_app.py`. Variables: `ADMIN_PASSWORD`, `SECRET_KEY`, `BOT_TOKEN` (жаппай хабарлама жіберу үшін керек), және сол бір `DATABASE_URL`.
4. Панель сервисінің Networking бөлімінен "Generate Domain" бас — соған кіріп, әкімші панеліне қол жеткізесің.
5. Екі сервис те бір `DATABASE_URL`-ды көретін болғандықтан, бот жазған тапсырыс/пайдаланушы деректерін панель бірден көреді, және керісінше.

⚠️ Екі сервиске де **бірдей** `DATABASE_URL` мәнін қою міндетті — әйтпесе қайтадан екі бөлек база пайда болады.

## 1. Орнату

```bash
pip install -r requirements.txt
```

## 2. Bot токенін алу

1. Telegram-да [@BotFather](https://t.me/BotFather) ашыңыз
2. `/newbot` жіберіп, атын қойыңыз (мыс. `Zhanakala Taxi Bot`)
3. Алынған токенді көшіріп алыңыз

## 3. Іске қосу

**Ең оңай нұсқа — бір команда, екеуі де бір процесте, бір базамен:**
```bash
export BOT_TOKEN="сенің_токеніңBotFather_берген"
export ADMIN_PASSWORD="өз_құпия_сөзің"
export ADMIN_CHAT_ID="сенің_telegram_id-ің"   # @userinfobot ботынан аласың
python3 app.py
```
Панель мына жерде ашылады: **http://localhost:10000** (портты `PORT` айнымалысымен өзгертуге болады).

**Ескі нұсқа (екі бөлек терминал, тек локал тестілеу үшін):** боттың мәзірлерін жеке-жеке қарау ыңғайлы болса, `bot.py` мен `admin_app.py`-ды бөлек іске қосуға да болады — бірақ екеуі де сол каталогтан іске қосылу керек (сонда ортақ `taxi.db` файлын көреді):
```bash
# Терминал 1
python3 bot.py
# Терминал 2
python3 admin_app.py
```
⚠️ Осы ескі нұсқаны **екі бөлек серверге/сервиске** (мыс. екі Render қызметіне) шығармаңыз — сол жағдайда әрқайсысы өз бетінше `taxi.db` жасайды да, дерек бөлек-бөлек қалады. Хостингте әрдайым `app.py`-ды қолдан.

## 4. Қалай жұмыс істейді

**Жолаушы:**
1. `/start` → "🧍 Жолаушымын" таңдайды → телефон нөмірін жібереді
2. "🚕 Такси шақыру" → қайдан, қайда, уақыты, бағасын өзі жазады
3. Тапсырыс барлық **онлайн** жүргізушілерге автоматты жіберіледі (push-хабарлама)
4. "❌ Болдырмау" батырмасымен тапсырысты кез келген уақытта (жол басталғанға дейін) болдырмауға болады
5. "📋 Менің сұраныстарым" — өз тапсырыстарының статусын көреді

**Жүргізуші:**
1. `/start` → "🚕 Жүргізушімін" таңдайды → телефон нөмірін жібереді
2. "🟢 Online болу" — енді жаңа тапсырыстар автоматты келеді (push); "🔴 Offline болу" — тоқтатады
3. Жаңа тапсырыс келгенде "✅ Қабылдау" басады (немесе "📋 Ашық тапсырыстар" арқылы қолмен қарайды)
4. Тапсырыс циклі: **Қабылдау → 📍 Жеттім → 🏁 Сапарды аяқтау** — әр қадамда жолаушыға автоматты хабарлама кетеді
5. Бір мезгілде тек бір белсенді тапсырыс жүргізе алады (алдыңғысын аяқтамай, жаңасын ала алмайды)
6. "💰 Табысым" — аяқталған сапар саны мен жалпы табысын көреді

**Әкімші (сен):**
- Веб-панельден барлық тапсырыс пен пайдаланушыны көресің (соның ішінде кім қазір онлайн)
- Тапсырысты кез келген сатыда мәжбүрлеп "Аяқтау" немесе "Болдырмау" қыла аласың
- Жалпы статистиканы (жолаушы, жүргізуші, онлайн жүргізуші саны, тапсырыстар) көресің

## Тапсырыс статустары
`open` (ашық, жүргізуші күтуде) → `accepted` (жүргізуші алды, жолда) → `arrived` (жүргізуші жеткен жерге келді) → `completed` (аяқталды). Кез келген сәтте `cancelled` (болдырылмады) болуы мүмкін.

## 📍 Геолокация
"Такси шақыру" барысында жолаушы "Қайдан" және "Қайда" сұрақтарында екі нұсқаны таңдай алады:
- **📍 Локация жіберу** батырмасы — Telegram картадан дәл нүктені жібереді
- Немесе жай мекенжайды мәтінмен жазады (мыс. "Жанақала, орталық")

Егер локация жіберілсе, координаттар базаға сақталады, жүргізушіге қабылдағанда Google Maps сілтемесі және Telegram-дың өзінде карта белгісі (location pin) автоматты жіберіледі. Әкімші панелінде де 🗺 сілтемесі көрінеді.

## ⭐ Рейтинг және тарих
- Сапар аяқталған соң жолаушыға автоматты 1-5 жұлдыз таңдауға батырмалар шығады
- Жүргізушінің орташа рейтингі есептеліп, келесі тапсырыс қабылданғанда жолаушыға көрсетіледі (мыс. "Жүргізуші: Болат ⭐4.8 (12 баға)")
- Жолаушы "📋 Менің сұраныстарым" арқылы өз тарихын (қойған бағасымен) көреді
- Жүргізуші "📜 Тарихым" арқылы аяқталған сапарларын, алған бағаларын көреді
- Әкімші панелінде: жалпы орташа рейтинг (дашборд), әр жүргізушінің жеке рейтингі (пайдаланушылар беті), әр тапсырыстың бағасы (тапсырыстар беті)
- Бір тапсырысты бір рет қана бағалауға болады

## 👨‍💻 Админ мүмкіндіктері (4-фаза)
- **Бұғаттау** — "Пайдаланушылар" бетінде әр адамның қасында "Бұғаттау/Ашу" батырмасы бар. Бұғатталған пайдаланушы боттың негізгі әрекеттерін (тапсырыс жасау, онлайн болу, тапсырыс қабылдау) орындай алмайды, бот оған себебін хабарлайды.
- **📢 Жаппай хабарлама** — "Хабарлама" бетінен барлығына, тек жолаушыларға немесе тек жүргізушілерге мәтіндік хабарлама жібере аласың. Бұл функция үшін `admin_app.py`-ды іске қосар алдында бот токенін де қосымша орнату керек:
  ```bash
  export BOT_TOKEN="сенің_бот_токенің"
  export ADMIN_PASSWORD="..."
  python3 admin_app.py
  ```
- **💼 Комиссия** — "Баптаулар" бетінде пайызды өзің қоясың (әдепкісі 10%). Дашбордта барлық аяқталған сапарлардан жиналатын жалпы комиссия сомасы автоматты есептеледі (баға өрісіндегі сандардың негізінде). Бұл тек есептеу үшін — ақша автоматты ұсталмайды, тек көрсеткіш ретінде жұмыс істейді.

## Жоба толық аяқталды 🎉
Барлық 4 фаза дайын: тапсырыс циклі + online/offline, геолокация, рейтинг/тарих, әкімші (бұғаттау/хабарлама/комиссия). Келесі қадам — @BotFather-дан токен алып, серверге (Railway/Render) шығарып, нақты пайдаланушылармен сынау.

## 5. Хостингке шығару (24/7 жұмыс істеуі үшін)

**Railway-де бот пен панельді екі бөлек сервис + ортақ PostgreSQL ретінде шығару — жоғарыдағы "🗄 Архитектура" бөлімін қара, бұл қазір ұсынылатын нұсқа.**

Төмендегі екі нұсқа (`app.py` арқылы бір процесс, SQLite-пен) — қарапайым локал тестілеу/шағын демо үшін әлі де жұмыс істейді:

### Нұсқа A — Railway (оңай, кодты өзгертпейді)
Ай сайын $5 несие беріледі — шағын бот үшін әдетте осының өзі жетеді, бірақ кепілдік жоқ (несие таусылса, аздаған ақы алынады).

1. `taxi-bot` папкасын GitHub-қа жүкте (жаңа репозиторий жасап)
2. [railway.app](https://railway.app) — GitHub арқылы кіру
3. "New Project" → "Deploy from GitHub repo" → репозиторийіңді таңда
4. Settings → Start Command = `python3 app.py`, Variables-қа `BOT_TOKEN`, `ADMIN_CHAT_ID`, `ADMIN_PASSWORD` қос — **бір ғана сервис жеткілікті**, себебі `app.py` бот пен панельді бірге, бір базамен іске қосады
5. Settings → Networking → "Generate Domain" — панельдің сілтемесін аласың
6. Деректер (`taxi.db`) сақталып қалады — Railway persistent volume қосуға болады (Settings → Volumes), бірақ бастапқы деплойда әдепкі диск те көбіне жеткілікті

### Нұсқа B — Render (шын тегін, бірақ дерек тұрақты сақталмайды)
Бот пен әкімші панелі енді **бір ғана Render сервисінде** (`app.py` арқылы) жұмыс істейді — бот фондық ағында (polling), панель негізгі ағында. Осылай екеуі әрқашан бір `taxi.db` файлын көреді.

1. `taxi-bot` папкасын (`render.yaml`-мен бірге) GitHub-қа жүкте
2. [render.com](https://render.com) → "New" → "Blueprint" → репозиторийіңді таңда — `render.yaml` бір сервисті автоматты жасайды
3. Сервистің Environment бөлімінде сұралған айнымалыларды толтыр (`BOT_TOKEN`, `ADMIN_CHAT_ID`, `ADMIN_PASSWORD`)
4. Деплой аяқталған соң, сол бір URL-де (мыс. `https://zhanakala-taxi-bot.onrender.com`) әкімші панелі ашылады, ал бот сол сәтте polling режимінде іске қосылады — қосымша webhook баптау керек емес

⚠️ **Ескерту:** Render-дің тегін жоспарында тұрақты диск жоқ — `taxi.db` әр қайта деплой/рестарт сайын өшіп кетуі мүмкін. Тестілеу үшін жеткілікті, бірақ нақты жолаушы/жүргізуші деректерін ұзақ сақтау керек болса:
- Render-де ақылы "Persistent Disk" қос, оны мыс. `/data`-ға mount ет, содан кейін `DB_PATH=/data/taxi.db` айнымалысын орнат (`database.py` мұны автоматты пайдаланады), немесе
- Railway (ақылы volume-мен) немесе арзан VPS қарастыр.

## 6. 📦 Жеткізу қызметі + 🛣 Жанақала — Орал бағыты (5-фаза)

**Жеткізу қызметі.** Жолаушы мәзірінде енді "🚕 Такси шақыру" қатарында "📦 Жеткізу шақыру" батырмасы бар. Ол сол циклмен жұмыс істейді (қайдан/қайда/уақыты/бағасы), тек алдымен "не жеткізу керек?" деп сипаттама сұрайды және жүргізушіге/әкімші панеліне 📦 деп белгіленіп көрінеді.

**Жанақала — Орал бағыты — админ рұқсатымен.** Тапсырыс жасаудың алдында пайдаланушы бағытты таңдайды: "🏙 Жанақала ішінде" (еркін) немесе "🛣 Жанақала — Орал" (тек әкімші рұқсат берген адамдарға). Егер пайдаланушыға әлі рұқсат берілмесе:
1. Бот оған "сұранысыңыз әкімшіге жіберілді" дейді және тапсырыс жасауды тоқтатады.
2. Сенің Telegram-ыңа (`ADMIN_CHAT_ID`) "✅ Рұқсат беру / ❌ Бас тарту" батырмалары бар хабарлама келеді — соны бассаң, шешім бірден қолданылады және пайдаланушыға хабарланады.
3. Рұқсатты веб-әкімші панелінен де ("Пайдаланушылар" беті) басқаруға болады.

Осыны іске қосу үшін `bot.py`-ды жіберер алдында өз Telegram chat id-іңді орната:
```bash
export ADMIN_CHAT_ID="сенің_telegram_id-ің"   # @userinfobot ботынан ала аласың
export BOT_TOKEN="..."
python3 bot.py
```
`ADMIN_CHAT_ID` орнатылмаса, сұраныс ешкімге жіберілмейді (лог-та ескерту шығады) — рұқсатты сол жағдайда тек веб-панельден бере аласың.

## 7. Дизайн жаңартылды

Әкімші панелі минималды, қазіргі заманғы стильге өзгертілді: Inter қаріпі, ашық палитра, жұмсақ көлеңкелер, дөңгеленген карточкалар, белсенді бетті бөлектейтін навигация. Функционалдығы өзгерген жоқ.

## 9. Жүргізушінің толық тіркелуі + верификация (6-фаза)

Енді жүргізуші телефон нөмірін жібергеннен кейін бірден мәзірге өтпейді — көлігін толық тіркеуі керек:
📱 телефон (бұрыннан бар) → 🚗 марка → 🚘 модель → 🔢 мемлекеттік нөмір → 🎨 түс → 📅 жыл → 📸 көлік фотосы.

Тіркелу аяқталған соң статус **🟡 верификация күтуде** болады, ал сенің Telegram-ыңа (`ADMIN_CHAT_ID`) көлік фотосымен бірге "✅ Растау / ❌ Қабылдамау" батырмалары келеді. Қабылдамасаң, себебін таңдайсың (фото анық емес / деректер сәйкес емес / басқа) — жүргізушіге сол себеппен хабарланады және ол "🔄 Қайта тіркелу" арқылы деректерін қайта жібере алады. **Админ растамайынша (✅ ) жүргізуші Online режиміне кіре алмайды** — бұл бот жағында да, веб-панельде де тексеріледі. Веб-панельдің жаңа **"Жүргізушілер"** бетінен де осының бәрін (тізім, растау/қабылдамау, online/offline мәжбүрлеп ауыстыру, рейтинг, табыс) басқара аласың.

## 10. Жүргізуші профилінің 3 деңгейі

**1-деңгей (міндетті, бұрыннан бар + жаңартылды):**
🟢/🔴 Online-Offline, 🔔 жаңа тапсырыс хабарламасы, 🚦 тапсырыс статустары (қабылдау→жеттім→аяқтау), 📞 жолаушыға қоңырау шалу батырмасы (`tel:` сілтемесі — телефон қолданбасын ашады), 🗺 навигация батырмасы (Google Maps), ❌ бас тарту себебі (алыс жол / баға төмен / көлік ақаулы / басқа — таңдағаннан кейін тапсырыс қайта ашық тапсырыстарға оралады және басқа жүргізушілерге қайта жіберіледі).

**2-деңгей:**
💰 күндік табыс (бүгінгі сапар саны мен сомасы бөлек көрсетіледі), 📊 жалпы статистика, ⭐ рейтинг ("👤 Профилім" / "⭐ Рейтингім" батырмалары), 🔄 тапсырысты басқа онлайн жүргізушіге беру (тізімнен таңдап беріледі, екі жаққа да хабарланады).

**3-деңгей:**
📍 жақын тапсырыстар (жүргізуші локациясын жіберсе, ашық тапсырыстар қашықтығы бойынша сұрыпталады), 🗺 live карта (жүргізуші сапар барысында локация жіберсе, ол автоматты жолаушыға да жіберіледі — трекинг), 💰 баға ұсыну (жүргізуші ашық тапсырысқа өз бағасын ұсынады, жолаушы "келісемін/жоқ" деп жауап береді).

Тапсырыс қабылданғанда енді екі жаққа да **толық ақпарат** шығады: жүргізуші жолаушының атын, телефонын көреді; жолаушы жүргізушінің атын, телефонын, көлігін (марка/модель/түс/жыл/нөмір) және көлік фотосын көреді.

## 11. Әкімші панелінің жаңа бөлімдері

- **Жүргізушілер** — толық тізім, верификация статусы, online/offline, рейтинг, табыс, растау/қабылдамау/бұғаттау бір беттен
- **Қала/Тариф** — жаңа қала/аудан қосу (қосу/өшіру/жою), бағыт тарифтерін (🏙 ішкі, 🛣 Орал) базалық баға + 1 км бағасы түрінде сақтау (қазір анықтамалық, автоматты есептеуге қосу үшін хабарласыңыз)
- **Басты бет** — 💰 күндік және айлық айналым, соған сәйкес комиссия бөлек карточкаларда; верификация күтіп тұрған жүргізуші болса, ескерту сілтемесі шығады
- Бұрыннан барлары (тапсырыстар, пайдаланушылар, хабарлама, баптаулар) өзгеріссіз қалды

## 12. Тағы не қосуға болады (ұсыныстар)

- 💳 Онлайн төлем (Kaspi Pay сілтемесі) — тапсырыс бағасын бірден төлеп қою
- 🗺 Бекітілген бағыттар тізімі (Жанақала—Орал, Жанақала—Ақтөбе т.б.) селектормен, еркін мәтін орнына
- 📅 Алдын ала тапсырыс беру (белгілі бір күн/уақытқа брондау)
- 🚨 SOS батырмасы — жол барысында жолаушы/жүргізуші әкімшіге дереу хабарлама жібере алатын
- 📊 Күнделікті/апталық автоматты есеп — әкімшіге таңертең статистика жіберу
- 🌐 Орысша/қазақша тіл таңдау (қазір тек қазақша)
- 👥 Бірнеше әкімші (қазір біреу ғана, `ADMIN_CHAT_ID`)

## 13. Бұл жаңарту: ортақ база, Артқа/Бас мәзір, қосымша функциялар

**🗄 Бот пен әкімші панелі енді бір базада (маңызды түзету).** Бұрын `render.yaml` бот пен панельді екі бөлек Render қызметі ретінде шығаратын — әрқайсысының өз, бір-бірінен тәуелсіз дискісі болғандықтан, екеуі іс жүзінде екі бөлек `taxi.db` файлымен жұмыс істеп жатты (панель боттың деректерін көрмейтін). Енді жаңа **`app.py`** бот пен панельді **бір процесте** (бот — фондық ағында, polling режимінде; панель — негізгі ағында) қосады, сондықтан екеуі әрқашан бір файлды оқып/жазады. `render.yaml` да бір сервиске дейін қысқартылды. Деректерді Render қайта іске қосқанда сақтап қалу үшін `DB_PATH` айнымалысын ақылы диск жолына бағыттауға болады (жоғарыдағы 5-бөлімді қара).

**⬅️ Артқа / 🏠 Бас мәзір батырмалары.** Көлік тіркеу (марка→модель→нөмір→түс→жыл→фото) және тапсырыс жасау (бағыт→не жеткізу→қайдан→қайда→уақыт→баға) сияқты барлық көп қадамды диалогтарда енді әр қадамда "⬅️ Артқа" (алдыңғы қадамға қайту) және "🏠 Бас мәзір" (кез келген жерден дереу негізгі мәзірге шығу) батырмалары бар.

**💡 Жол ақысын болжау.** "Қала/Тариф" бетінде тариф (базалық баға + 1 км бағасы) қойылған болса, жолаушы локация арқылы қайдан/қайда енгізгенде бот қашықтықты өзі есептеп, ұсынылатын бағаны көрсетеді (соңғы шешім — жолаушыда).

**⭐ Жүргізуші жолаушыны да бағалайды.** Сапар аяқталғанда енді екі жақ та бір-бірін бағалайды (бұрын тек жолаушы жүргізушіні бағалайтын).

**🆘 Қолдау қызметі.** Жолаушы/жүргізуші мәзірінде жаңа батырма — тікелей әкімшіге хабарлама жазуға болады. Әкімші панелінде жаңа **"Қолдау"** беті хабарламаларды тізбек (чат) түрінде көрсетеді, сол жерден жауап жазуға болады (жауап Telegram арқылы автоматты жіберіледі). Оқылмаған хабарлар саны навигацияда көрінеді.

**📤 CSV экспорт және іздеу.** "Пайдаланушылар" бетінде аты/username/телефон бойынша іздеу қосылды; "Пайдаланушылар" және "Тапсырыстар" беттерінде деректерді CSV файл ретінде жүктеп алуға болады.
